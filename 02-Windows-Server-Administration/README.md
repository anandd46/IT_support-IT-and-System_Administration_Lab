## Prerequisites

- Oracle VirtualBox 7.x installed on the host machine
- Windows Server 2022 ISO (Evaluation edition available from Microsoft)
- Minimum 4 GB RAM allocated to the VM (8 GB recommended)
- Minimum 60 GB disk space for the VM
- Host machine with at least 16 GB RAM recommended
