### Physical Hardware Checks
- [ ] Power and video cables securely latched.
- [ ] Chassis exterior and vents wiped clean.
- [ ] Internal fans and heatsinks blown clear of dust.
- [ ] Case fans spinning freely with zero bearing noise.
- [ ] Display monitor cleaned with microfibre cloth.
- [ ] Keyboard and mouse sanitized and tested.

### Operating System & Security Checks
- [ ] Windows Cumulative Updates current.
- [ ] Microsoft Defender / Antivirus signatures up to date.
- [ ] Drive C: has > 20% free storage space remaining.
- [ ] Temporary files purged (`%temp%` and `cleanmgr`).
- [ ] Event Viewer audited for recurring hardware/disk errors.
- [ ] CrystalDiskInfo S.M.A.R.T. health confirms "Good".

### Network & Performance Checks
- [ ] Workstation negotiates 1 Gbps Full Duplex on switch port.
- [ ] Default gateway and DNS server pings respond in <2ms.
- [ ] Startup applications audited; high-impact bloat disabled.
- [ ] Memory utilization normal under baseline workload.
