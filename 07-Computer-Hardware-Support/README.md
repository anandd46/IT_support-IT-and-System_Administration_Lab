# Module 07 — Computer Hardware Support

This module covers computer hardware identification, diagnostics, and maintenance procedures.

## Safety First

> **Important Safety Rules:**
> - Always power off the computer and disconnect the power cable before opening a desktop case.
> - Use an ESD (Electrostatic Discharge) wrist strap or touch a metal surface to discharge static electricity before touching components.
> - Do not force connectors — if something does not fit easily, check alignment.
> - Laptop internal components should only be replaced by qualified technicians unless you have the appropriate model service manual.
> - Follow your organisation's change-control procedures before replacing hardware in a production environment.
